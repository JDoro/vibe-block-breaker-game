# Vibe Block Breaker

A classic arcade-style block breaker game built with vanilla JavaScript, HTML5 Canvas, and CSS. Break all the blocks to win!

## 🎮 Play the Game

[Play Now on GitHub Pages](https://jdoro.github.io/vibe-block-breaker-game/)

## 🎯 How to Play

- **Objective**: Break all the colored blocks by bouncing the ball off your paddle
- **Controls**: Move your mouse or use touch to control the paddle position
- **Lives**: You start with 3 lives. Lose a life when the ball falls off the bottom
- **Scoring**: Each block broken earns you 10 points
- **Win Condition**: Break all 40 blocks to win the game
- **Lose Condition**: Lose all 3 lives

## ✨ Features

- 🎨 Vibrant gradient background and colorful blocks
- 📱 Fully responsive design - works on desktop and mobile
- 🖱️ Mouse and touch controls
- 💫 Smooth animations and visual effects
- 🎮 Classic arcade gameplay mechanics
- 🏆 Score tracking and lives system

## 🛠️ Technical Details

Built with:
- Pure vanilla JavaScript (no frameworks)
- HTML5 Canvas for rendering
- CSS3 for styling and responsive design
- No external dependencies

## 🚀 Local Development

To run the game locally:

1. Clone this repository
```bash
git clone https://github.com/JDoro/vibe-block-breaker-game.git
cd vibe-block-breaker-game
```

2. Open `index.html` in your web browser, or serve it with a local server:
```bash
python3 -m http.server 8080
# Then open http://localhost:8080 in your browser
```
